1. Problem & LCM Pedagogy 🧠
Critical Bottleneck

1-to-1 Mentorship Scaling Crisis

InclusiveMinds (IMLC) mentors children with Autism and ADHD through strengths-based plans. Only one fully qualified companion existed. Training new companions was 100% manual, slow, and unstandardized.

⚠️ Preparation Overhead: Hours spent searching internet for activities.
⚠️ Cognitive Risk: Inconsistent handling of sensory overload meltdowns.

The 4 LCM Pillars Pedagogy

🎬 LED (Learning by Dialogue/Exposition) Video simulations with synchronized, non-skippable reflection pause stops.
📄 LBD (Learning by Doing) Sequential PDF milestone reading guides with anti-spoiler reflection questions.
🚀 LxT (Extension Trajectory) Advanced multi-video clinical case studies unlocked only upon lesson completion.
💬 LxI (Interactive Peer Space) Module-scoped discussion forum with anti-stale prompt answer protection.

2. Architecture & Resilience ⚙️

Hybrid Dual-Engine Architecture

Engineered with a fail-safe hybrid pipeline that bridges full-stack cloud capabilities with offline local continuity during grading:

🖥️ Frontend SPA (HTML5 • TailwindCSS • Vite Bundler)
↓ ↑ REST & Telemetry Sync
⚙️ Full-Stack Backend API (Express.js :5050 • JWT Auth)
↓ ↑ Fail-Safe Persistence
🍃 MongoDB Atlas
💾 File-Backed Fallback
Live Dynamic Status Pill 🟢 Online Mode

If MongoDB or server drops, the UI transitions to 🟡 Offline LocalStorage mode with zero crashes and 100% data retention.

IndexedDB PDF Vault & Draft Isolation

🗄️ IndexedDB Vault (lcs_pdf_vault) Stores multi-page clinical protocols directly in client binary storage, completely bypassing the 5MB LocalStorage quota.
🔄 Draft vs. Live Publishing Isolation Authors modify drafts in draftDb without interrupting active companion training sessions until explicit one-click publishing to publishedDb.
3. Interactive Delivery 🎯

Universal Video Engine

YouTube API

Full-featured media layer supporting both MP4 video streams and raw YouTube links with automated ID extraction.

Non-Skippable In-Video Checkpoint Pause

Continuous 500ms timestamp polling automatically forces pause at reflection intervals (e.g. 00:15). Playback resumes only upon submitting a valid intervention.

Gated PDF Reading Stops

Anti-Spoiler

Checkpoints are not thrown out all at once. Trainees advance through reading milestones page-by-page.

Milestone 1 Milestone 2 Milestone 3
✓ Page 1 Read → ❓ Checkpoint Unlocked → 🔒 Next Milestone
🔒

Strict Master Quiz Gating

Certification assessments stay locked until 100% of submodules, videos, PDFs, and reflections are completed.
